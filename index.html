KitchenBase API

KitchenBase is a REST API for managing recipes, users and categories.

Recipe Endpoints

GET /recipes

Get all recipes.

GET /recipes/:id

Get one recipe by its ID.

POST /recipes

Add a new recipe.

{
  "name": "Mushroom Soup",
  "ingredients": "Mushroom, milk, salt",
  "author": 1,
  "category": 1,
  "instructions": "Cook all ingredients together."
}

User Endpoints

GET /users

Get all users.

POST /users

Add a new user.

{
  "username": "Sarah"
}

Category Endpoints

GET /categories

Get all categories.
